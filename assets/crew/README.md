# クルー差し替え用フォルダ

自作の `.glb` モデルを置くと、メニューのクルー選択に追加されます。

1. このフォルダに `.glb` を置く(例: `mychar.glb`)
2. `manifest.json` に登録する

```json
{ "models": [ { "name": "マイキャラ", "file": "mychar.glb", "height": 0.95 } ] }
```

- `height` は座った状態の全高(m)。自動でスケールされます。
- モデルの前方は **-Z 方向**、足元が原点になるようにしてください。
- 版権のあるキャラクターは、公開・配布しないでください(個人利用の範囲で)。
